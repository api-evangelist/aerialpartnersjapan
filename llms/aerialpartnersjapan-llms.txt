# Aerial Partners

> 株式会社Aerial Partners (Roppongi, Minato-ku, Tokyo) builds digital-asset accounting, tax and
> data-management software for the Japanese market. It sells AWA (Aerial Web3 Accounting), an
> accounting-support tool for Web3 businesses handling crypto assets and NFTs, and ADM (Aerial Data
> Management), a management-accounting and statutory-ledger data platform for crypto-asset exchange
> operators and Type I financial instruments business operators. It also fronts Lukka Insights for
> its parent, Lukka, which acquired the company in January 2025. Aerial Partners publishes NO public
> developer portal, NO API reference and NO machine-readable contract. This file is generated by API
> Evangelist from public pages; it is not published by Aerial Partners.

## What an agent can and cannot do here

- There is no public API. No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL or Postman collection is
  published on any host the company controls (aerial-p.com, crypto-city.net,
  support.crypto-city.net). Probed 2026-09-10.
- No /.well-known document is served on any of those hosts. crypto-city.net answers HTTP 200 with a
  single-page-app HTML shell on several /.well-known paths; those are not documents.
- No MCP server, no A2A agent card, no llms.txt of the company's own.
- The only API the company markets is the "Gtax Network API", a joint-development BtoBtoC offering
  for exchange operators. It is reachable only through the corporate inquiry form.
- Aerial Partners is primarily an API CONSUMER: its Gtax lineage read transaction history from
  roughly seventy crypto exchanges and wallets using customer-supplied, read-only exchange API keys.

## Products

- [AWA (Aerial Web3 Accounting)](https://www.aerial-p.com/others/awa.html): accounting support for Web3 operators; product site at https://crypto-city.net/awa.
- [ADM (Aerial Data Management)](https://www.aerial-p.com/service): data management, management accounting and statutory ledgers for financial institutions. Formerly "Gtax Enterprise Edition"; renamed 2021.
- [Gtax Network](https://www.aerial-p.com/others/gtax_network.html): BtoBtoC profit-and-loss calculation platform for exchange operators. Phase 1 is described as 「GtaxネットワークAPI」.
- [Lukka Insights](https://www.aerial-p.com/others/lukka.html): the parent company's crypto data platform, fronted in Japan.

## Lifecycle you should know before integrating

- 2025-01-27: Lukka acquired Aerial Partners.
- 2025-08-31: the コイン相場 (Coin Souba) mobile app was discontinued.
- 2026-07-01: pafin acquired 株式会社Gtax. Gtax and the Guardian tax-filing service, both originated
  by Aerial Partners, left the company. Gtax stopped taking new registrations the same day.
- 2026-09-27: last day of Gtax service. Login closes 2026-09-28; accounts move to Cryptact
